# Calendario AdminClases

Feed `.ics` con las clases **pendientes** y las **actividades** de AdminClases.
Todo lo demás (facturadas, vencidas, canceladas, reservadas) se ignora.

## Suscripción

**Google Calendar (Android o web):** Ajustes → Añadir calendario → **Desde URL** → pegar:

```
https://lunasolYulika.github.io/calendario-adminclases/AdminClases.ics
```

**iPhone / iPad:** Ajustes → Calendario → Cuentas → Añadir cuenta → Otro →
**Añadir calendario suscrito** → pegar la misma URL.

## Cómo se actualiza

1. En AdminClases: menú **Agenda → Exportar calendario (.ics)** (escribe
   `AdminClases.ics` junto al programa).
2. Doble clic en `publicar-calendario.cmd` (carpeta del programa).
3. El calendario del celular se refresca solo en unos minutos.

Una clase que pasa de pendiente a facturada (o se cancela) desaparece sola del
calendario en la próxima publicación.
